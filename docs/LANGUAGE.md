# Application language

2026-10-25, beta6.7: application-generated dashboard, PS5 notifications, connection/error reasons and diagnostic text use English. Startup, pairing, disconnect, virtual-controller errors, rest-mode shutdown and duplicate-instance notifications have been translated. Protocol/API identifiers remain unchanged. Historical log files are not rewritten; old Spanish entries may still appear in their history. Messages produced by PS5 system software or third-party apps are outside this translation.

The manual-USB build preserves the current Bluetooth investigation mode, with automatic USB scanning disabled. It does not claim to fix the outstanding post-hotplug connection failure.
