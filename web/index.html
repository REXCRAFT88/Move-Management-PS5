Phone camera

For phones without USB Webcam mode, run IP Webcam or CamRelay on the same local network. Enter the displayed address and port; /video is added automatically. Custom stream paths also work. USB alone does not enable this connection.

Phone takes priority when configured. USB webcam or PS3 Eye is used if its stream stops. For smoother tracking, use 640x480 and moderate JPEG quality. Color enhancement helps detect dim spheres without changing the preview. No video is recorded.

Navigation controllers supply buttons and a stick; only Move spheres are optically tracked. Camera position is available alongside the Move’s gyro. Camera-based pointer correction is still being calibrated.

MAKE MOTION FEEL RIGHT

Calibrate your Move.

Calibrate each Move separately. Place it on a stable surface with every button released.

Stationary gyro calibration

Leave the controller completely still, then select Start. Keep it still for three seconds. Movement cancels the attempt and preserves the previous calibration.

Connect a Move to begin.

This corrects stationary gyro drift for this connection. Recalibrate after reconnecting. Factory sensor calibration is preserved; if unavailable, connect the Move by USB first.

Check your aiming

  1. After gyro calibration, pick up the Move and point at the TV center.
  2. In the emulator, press and release Select to recenter.
  3. Tilt up/down and turn left/right. If aiming feels too fast or reversed, adjust the player’s motion settings in Button layouts.

Gyro zeroing does not set the screen center or calibrate optical position. Use Camera tracking to frame the spheres and mark wall lights to ignore. Camera-based pointer correction is still experimental.

Navigation controllers have no Move gyro to calibrate. Their stick and buttons are configured in Button layouts.

Screen aiming calibration

Use the connected Move selected above. Open this page on your TV, or use the TV’s corresponding center and corner positions. Sit where you will play. Calibrate gyro drift first.

Select Set up aiming, then follow the targets using the Move button.

Confirm with the physical Move button, not X. Targets are inset 10% from each edge, matching Porpoise. Save stores screen geometry per player; press Select to recenter the Move Management test pointer. This calibration does not modify Porpoise or other apps.
